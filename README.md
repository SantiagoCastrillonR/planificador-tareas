# Planificador de Tareas - Sprint 1

**Por: Santiago Castrillón Rojo**  

## 1. Descripción del proyecto
El Planificador de Tareas es una aplicación web interactiva diseñada para facilitar la organización y el seguimiento de actividades. En este primer Sprint, se desarrolló una interfaz responsiva utilizando HTML5 y Bootstrap 5, permitiendo a los usuarios visualizar una lista de tareas (pendientes, en progreso, completadas) y registrar nuevas actividades mediante un formulario. Además, se implementó lógica en JavaScript para validar que los datos ingresados en el formulario sean correctos antes de ser procesados, brindando retroalimentación visual inmediata mediante SweetAlert2.
